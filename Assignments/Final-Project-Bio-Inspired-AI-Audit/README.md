# Final-Project-Bio-Inspired-AI-Audit

This final project evaluated ChatGPT through a neuroscience lens by analyzing memory, attention, perception, reasoning, and cognitive load using structured experiments inspired by biological cognition.

## Project Overview

The goal of this project was to determine how closely artificial intelligence systems resemble biological cognitive processes found in the human brain. The project analyzed whether ChatGPT demonstrates true memory, attention, perception, and reasoning or if it primarily relies on learned statistical patterns.

A series of neuroscience-inspired experiments were conducted using concepts from multiple course modules. These experiments tested how the AI handled:
- memory interference
- selective attention
- reasoning and world models
- ambiguous perception
- cognitive load
- instruction prioritization

The project compared AI behavior to biological systems discussed throughout the course, including hippocampal memory consolidation, attention systems, perception pipelines, and distributed world modeling.

# Experiments Included

## Experiment 1 — Memory, Interference, and False Memory
Tested whether ChatGPT could retain information after interference and whether conflicting information could influence recall. The experiment compared AI context retention to hippocampal memory consolidation and reconstructive memory in humans.

## Experiment 2 — Selective Attention and Inattentional Blindness
Tested whether ChatGPT would prioritize dominant instructions while ignoring hidden or conflicting commands embedded inside text. The experiment compared AI instruction prioritization to biological selective attention systems. 

## Experiment 3 — Reasoning and World Models
Tested whether ChatGPT could reason about physics scenarios involving gravity, inertia, and force while adapting to modified conditions. The experiment connected AI reasoning behavior to Thousand Brains Theory and distributed world modeling. 

## Experiment 4 — Perception and Ambiguity
Tested how ChatGPT handled vague and ambiguous scenarios while reporting assumptions and confidence levels. The experiment compared AI pattern-based interpretation to biological sensory perception systems.

## Experiment 5 — Cognitive Load and Instruction Prioritization
Tested how ChatGPT handled multiple competing instructions while maintaining task prioritization. The experiment compared AI processing to biological cognitive load limitations.

# Reflection

This final project helped me combine multiple neuroscience concepts learned throughout the course and apply them to the evaluation of a real-world artificial intelligence system. By conducting structured experiments on ChatGPT, I was able to directly compare AI behavior to biological processes involving memory, attention, perception, reasoning, and cognitive load.

One of the most important findings from this project was that ChatGPT can simulate many behaviors that appear intelligent while still lacking the underlying biological mechanisms found in the human brain. The AI demonstrated strong performance in reasoning, task prioritization, and contextual responses, but it still relied heavily on context windows, statistical relationships, and learned patterns rather than true memory consolidation or grounded understanding. 

The memory experiments demonstrated that ChatGPT does not truly store information like humans do. Instead of using hippocampal consolidation, the AI temporarily retains information within the visible conversation context. This creates the appearance of memory while lacking long-term storage or reconstructive memory processes found in biological cognition.

The perception and ambiguity experiments also highlighted major differences between AI systems and biological sensory systems. Humans rely on visual, auditory, and environmental information to resolve uncertainty, while the AI relied entirely on language patterns and prior text-based knowledge. This demonstrated that ChatGPT simulates perception without true sensory grounding.

Another major takeaway from this project was understanding how neuroscience principles can guide the future development of AI systems. Concepts such as memory consolidation, world models, attention limitations, and time-based processing could help future AI systems become more adaptive, realistic, and biologically inspired.

Overall, this project strengthened my understanding of neuroscience-inspired artificial intelligence and demonstrated both the strengths and limitations of modern AI systems when compared to human cognition. It also showed how neuroscience can provide valuable insight into improving future AI architectures and intelligent systems.
