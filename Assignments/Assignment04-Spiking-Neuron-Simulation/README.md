# Assignment04-Spiking-Neuron-Simulation

This assignment explored spiking neuron behavior using the Leaky Integrate-and-Fire (LIF) neuron model in Wolfram Mathematica.

## Reflection

This assignment helped me better understand how biological neurons process information through spikes and membrane potential changes over time. By implementing the Leaky Integrate-and-Fire (LIF) model in Wolfram Mathematica, I was able to observe how neuron behavior changes depending on parameters such as threshold, membrane time constant, and input current.

One of the most interesting parts of the assignment was using the interactive Manipulate[] dashboard to explore neuron behavior in real time. By adjusting the sliders, I could immediately see how small parameter changes affected spike generation and firing rates. This made the concepts much easier to understand compared to only reading about neurons in the booklet.

I also learned how neurons encode information through spike trains. When using sinusoidal and noisy input signals, the neuron responded by changing the frequency and timing of spikes. This demonstrated how biological neurons can convert continuous analog signals into discrete spike patterns while still preserving important information about the stimulus.

The experiments with threshold sweeps and membrane time constants also helped me understand how biological neurons make decisions about whether to fire. Lower thresholds and smaller time constants produced more spikes, while higher thresholds and larger time constants reduced firing activity. This showed how neuron parameters strongly influence neural communication and information processing.

Overall, this assignment strengthened my understanding of neuroscience-inspired AI and demonstrated how simplified neuron models can still capture important biological behaviors such as threshold activation, spike generation, refractory periods, and signal encoding. It also showed how neuroscience concepts can inspire more advanced AI systems such as spiking neural networks and energy-efficient computing models.
