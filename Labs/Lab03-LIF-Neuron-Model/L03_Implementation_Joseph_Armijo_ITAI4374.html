PART 1: BIOLOGICAL NEURON SIMULATION

Biological Neuron Class

class BiologicalNeuron:
    """Simulates simplified biological neuron characteristics"""

    def __init__(self):
        self.resting_potential = -70  # mV
        self.threshold = -55         # mV
        self.peak = 40               # mV (action potential peak)
        self.refractory_period = 5   # time steps
        self.decay_rate = 0.1

    def simulate_response(self, input_current, time_steps=100):
        membrane_potential = self.resting_potential
        membrane_potentials = []
        refractory_counter = 0

        for t in range(time_steps):

            if refractory_counter > 0:
                refractory_counter -= 1
                membrane_potential = self.resting_potential

            else:
                membrane_potential += input_current

                if membrane_potential >= self.threshold:
                    membrane_potential = self.peak
                    refractory_counter = self.refractory_period

                membrane_potential -= self.decay_rate

            membrane_potentials.append(membrane_potential)

        return membrane_potentials

Biological Neuron Response to Different Inputs – Analysis¶

From the graph, the neuron's behavior clearly depends on the strength of the input current.

  • When the input current is 0.2, the membrane potential slowly increases but never reaches the threshold of -55 mV. Because of this, no action potential is generated.
  • When the input current is 0.8, the neuron occasionally reaches threshold and produces action potentials (spikes up to about 40 mV).
  • When the input current is 1.5, the neuron spikes much more frequently.

This demonstrates the all-or-none principle. The neuron does not partially fire — once threshold is reached, a full spike occurs. If threshold is not reached, no spike happens at all.

The graph also shows the effect of the refractory period. After each spike, the membrane potential resets near the resting potential (-70 mV), preventing immediate re-firing.

Overall, this shows that biological neurons encode information through spike frequency. Stronger input currents produce more frequent action potentials, which is how biological systems transmit information.

PART 2: ARTIFICIAL NEURON

Artificial Neuron Class

In [4]:
class ArtificialNeuron:
    """Implements artificial neuron"""

    def __init__(self, num_inputs):
        self.weights = np.random.randn(num_inputs)
        self.bias = 0

    def activate(self, inputs, activation="sigmoid"):
        weighted_sum = np.dot(self.weights, inputs) + self.bias

        if activation == "sigmoid":
            return 1 / (1 + np.exp(-weighted_sum))

        elif activation == "relu":
            return max(0, weighted_sum)

        elif activation == "tanh":
            return np.tanh(weighted_sum)

        else:
            return weighted_sum

Compare Activation Functions

neuron = ArtificialNeuron(1)

x_values = np.linspace(-10, 10, 100)
sigmoid_outputs = []
relu_outputs = []
tanh_outputs = []

for x in x_values:
    sigmoid_outputs.append(1 / (1 + np.exp(-x)))
    relu_outputs.append(max(0, x))
    tanh_outputs.append(np.tanh(x))

plt.figure()
plt.plot(x_values, sigmoid_outputs, label="Sigmoid")
plt.plot(x_values, relu_outputs, label="ReLU")
plt.plot(x_values, tanh_outputs, label="Tanh")

plt.title("Activation Function Comparison")
plt.legend()
plt.show()

Activation Function Comparison – Analysis¶

From the graph:

  • Sigmoid produces a smooth S-shaped curve between 0 and 1.
  • ReLU outputs 0 for all negative inputs and increases linearly for positive values.
  • Tanh is similar to sigmoid but ranges from -1 to 1 and is centered at zero.

Key Observations¶

  • ReLU grows much faster than sigmoid or tanh for positive inputs.
  • Sigmoid compresses large values into a small range, which can cause vanishing gradient issues in deep networks.
  • Tanh provides negative outputs, which often helps learning because it is zero-centered.

Unlike biological neurons, none of these activation functions create a true spike. They produce continuous outputs instead of discrete action potentials.

PART 3: SIMPLE NETWORKS

Simple Feedforward Artificial Network

In [6]:
class SimpleNetwork:
    def __init__(self):
        self.hidden1 = ArtificialNeuron(2)
        self.hidden2 = ArtificialNeuron(2)
        self.output = ArtificialNeuron(2)

    def forward(self, inputs):
        h1 = self.hidden1.activate(inputs)
        h2 = self.hidden2.activate(inputs)

        hidden_outputs = np.array([h1, h2])
        final_output = self.output.activate(hidden_outputs)

        return final_output

Observations¶

  • The outputs are continuous values between 0 and 1.
  • The network responds slightly differently to each input combination.
  • There is no timing, no spikes, and no refractory period.
  • The network processes information instantly in a single forward pass.

This is very different from biological neurons, which:

  • Process information over time
  • Encode information in spike frequency
  • Have physical constraints like refractory periods

Simple Biological Network (2 neurons)

neuron1 = BiologicalNeuron()
neuron2 = BiologicalNeuron()

input_signal = 1.2

response1 = neuron1.simulate_response(input_signal)
response2 = neuron2.simulate_response(np.mean(response1)/100)

plt.figure()
plt.plot(response1, label="Neuron 1")
plt.plot(response2, label="Neuron 2")
plt.title("Simple Biological Network Response")
plt.legend()
plt.show()

Simple Biological Network – Analysis¶

From the biological network graph:

  • Neuron 1 clearly shows repeated action potentials (spikes reaching around 40 mV).
  • After each spike, it resets close to the resting potential (around -70 mV).
  • The refractory period prevents immediate re-firing.
  • Neuron 2 does not spike. Its membrane potential gradually decreases over time.

Why This Happened¶

Neuron 2 received the average membrane potential of Neuron 1 divided by 100. That input was too weak to push Neuron 2 past its threshold of -55 mV. Because of this, it never generated an action potential.

This demonstrates an important biological principle:

If synaptic input is not strong enough, downstream neurons will not fire.

Biological networks depend on:

  • Signal strength
  • Timing
  • Threshold accumulation
