Knowledge Check¶

  1. Why is V_reset (-75 mV) lower than V_rest (-70 mV)? What biological phenomenon does this represent?

Following a spike, real neurons go into an after-hyperpolarization phase, in which the membrane potential is more negative than at rest. This is due to the opening of the potassium channels, making the neuron less excitable.

  1. The time constant tau is 20 ms. In plain English, what does this control?

The time constant determines the speed at which the membrane potential responds to input.

  • If tau is small, the membrane voltage changes quickly, making sharp changes.

  • If tau is large, the membrane voltage changes slowly, making smooth changes.

In other words, the time constant controls how sluggish or responsive the neuron is.

PART B — Encoding Data as Spikes¶

Rate Coding

In [84]:
def rate_encode(values, num_steps=100):

    num_neurons = len(values)
    spikes = np.zeros((num_steps, num_neurons))

    for t in range(num_steps):
        spikes[t] = (np.random.rand(num_neurons) < values).astype(float)

    return spikes

Temporal Coding

In [86]:
def temporal_encode(values, num_steps=100, threshold=0.05):

    num_neurons = len(values)
    spikes = np.zeros((num_steps, num_neurons))

    for i in range(num_neurons):

        if values[i] > threshold:

            spike_time = int((1 - values[i]) * (num_steps - 1))

            spikes[spike_time, i] = 1

    return spikes

Knowledge Check¶

  1. In rate coding, what information is lost about the original signal?

In rate coding, the time at which the spikes occurred is lost. It only records the rate at which the neurons are firing, not the time at which the signals are occurring.

  1. Why might temporal coding allow faster decisions?

Temporal coding uses the time to the first spike to represent the information. This is why the system doesn't have to wait for the rate to be established; the first spike is enough to represent the information.

  1. Can you think of a real-world example where timing matters more than frequency?

A real-life scenario I think that can illustrate the difference between the two types of coding is the detection of the motion of an object. In the detection of the motion of an object, the exact timing of the spikes is important. Neighboring neurons have spikes that occur at precise times, which helps the brain determine the direction of the motion of the object.

REFLECTION¶

Compare your two raster plots. Which encoding would be better for a system that needs to react quickly? Which would be better for a system that needs precise measurements? The brain uses both strategies in different circuits — why do you think that is?

Temporal coding would be appropriate in a system that has to respond rapidly, since the timing of the first spike is used to encode the information, and a decision can be made almost instantaneously. Rate coding would be appropriate in a system in which accurate measurement is necessary, since the average of many spikes is a reliable and noise-resistant measurement of the signal's intensity. Both methods are used in the brain because different systems have different needs, and some systems, like those used in motion detection, need to respond rapidly, while others, like those used in perception and decision-making, need to be accurate.

weights[2,4] = 10.0
weights[3,4] = 10.0

I_ext = np.zeros((steps, N))

I_ext[100:400,0] = 18.0
I_ext[150:350,1] = 18.0

V_net = np.full((steps, N), V_rest)

spike_log = [[] for _ in range(N)]

Network Simulation

In [89]:
for t in range(steps - 1):

    # Track neurons that spike at this timestep
    spiked_now = np.zeros(N)

    for n in range(N):

        # External input current
        I_total = I_ext[t, n]

        # Synaptic input from neurons that spiked in previous step
        for j in range(N):
            if len(spike_log[j]) > 0:
                if spike_log[j][-1] == time_net[t]:
                    I_total += weights[j, n]

        # LIF voltage update
        dV = dt * (-(V_net[t, n] - V_rest) / tau + I_total / C)

        V_net[t+1, n] = V_net[t, n] + dV

        # Spike detection
        if V_net[t+1, n] >= V_thresh:
            spike_log[n].append(time_net[t+1])
            V_net[t+1, n] = V_reset
            spiked_now[n] = 1

for n in range(N):

    print(f"Neuron {n}: {len(spike_log[n])} spikes")

Knowledge Check

  1. Does the output neuron fire at the same rate as the input neurons? Why or why not?

The output neuron fires less because it only fires when it receives enough combined excitatory inputs from neurons 2 and 3. Since it is dependent on the activity of the other neurons rather than receiving a direct external current, the output neuron fires less often than the input neurons.

  1. What role do the synaptic weights play? What would happen if you doubled them? Halved them?

The synaptic weights control the strength of the interactions between the neurons. The greater the weight, the greater the likelihood that the output neuron will fire. The lower the weight, the lower the likelihood that the output neuron will fire. If the synaptic weights were doubled, the output neuron would fire more often; if the synaptic weights were halved, the output neuron would fire less often.

  1. In the brain, not all connections are excitatory. What might happen if you made weights[3, 4] negative (inhibitory)?

If the synaptic weight between neurons 3 and 4 is made inhibitory, the output will not spike, since the inhibitory input will cancel the excitatory input coming from neuron 2.

Part E: Final Reflection¶

  1. How does changing the membrane time constant (τ) affect firing behavior? What biological property does this represent? (Think about different types of neurons in the brain.)

The change in the time constant of the membrane will influence the rate at which the neuron’s membrane potential will change in response to the input. If the time constant is smaller, the change in the voltage will occur more rapidly, thus enabling the neuron to reach the threshold more quickly. This will cause the neuron to fire more rapidly.

The biological significance of the time constant is the difference in the properties of the neuron’s membrane, such as the resistance and capacitance of the neuron’s membrane. Different neurons in the human brain have different time constants, depending on their structure and function. Some neurons respond more rapidly to stimuli, while others respond more slowly.

  1. Compare your rate coding and temporal coding results. Which encoding preserved more information about the original signal? Why might the brain use both strategies in different circuits?

Rate coding conveys information based on the number of spikes over time. For my results, the more the value of the signal, the more the number of spikes. The disadvantage is that the timing of the spikes is lost.

Temporal coding stores information based on the timing of the spike. The stronger the signal, the earlier the spike is generated. This is faster in conveying information because the system does not have to wait for the rate of the spike to be generated.

The brain is likely using both rate coding and temporal coding because the brain is able to handle information in different ways depending on the task at hand.

  1. In your mini SNN, what happened when spikes propagated through layers? How does this relate to how information flows through real neural circuits?

The mini spiking neural network had spikes coming from the input neuron, and this affected the hidden neuron, which in turn affected the output neuron. The spikes transmitted signals in the network based on the links and weights of the network.

This is similar to how signals are transmitted in the human body. Neurons transmit signals in the human body, and signals in one neuron may transmit signals to other neurons. The structure of the network also affects how signals are transmitted.

  1. The LIF model is a simplification. What does it capture well about real neurons? What important biological features does it miss? (Think: dendrites, neurotransmitters, morphology, adaptation.)

The LIF model demonstrates some of the key aspects of the way in which real neurons behave. For example, the model demonstrates the way in which the neuron responds to the signals that are fed into it, the way in which the neuron fires in response to the accumulation of signal strength, and the way in which the neuron resets after the signal has been fired.

However, the LIF model does not demonstrate many of the key aspects of the way in which the brain works. For example, the brain is made up of many complex structures that play an important role in the way in which the brain works. Additionally, the brain uses many neurotransmitters in order to function. Furthermore, the brain is capable of adapting in many ways.
