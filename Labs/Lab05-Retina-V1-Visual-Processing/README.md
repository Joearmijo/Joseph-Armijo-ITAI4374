# Lab05-Bio-Inspired-Perception-Pipeline

This lab explored bio-inspired visual processing systems, retina-inspired filtering, V1 edge detection, and computer vision concepts using Python and Google Colab.

## Objectives

- Simulate retina-inspired visual processing
- Implement center-surround receptive fields
- Explore Difference of Gaussians (DoG) filtering
- Apply Gabor filters for edge and orientation detection
- Understand how the visual cortex processes images
- Compare biological vision systems to convolutional neural networks (CNNs)

## Technologies Used

- Python
- Google Colab
- NumPy
- Matplotlib
- OpenCV
- SciPy

## Key Concepts

- Retina Processing
- Center-Surround Receptive Fields
- Difference of Gaussians (DoG)
- Gabor Filters
- Edge Detection
- Orientation Selectivity
- Visual Cortex (V1)
- Computer Vision
- Bio-Inspired AI

## Reflection

This lab helped me better understand how biological vision systems inspired many modern computer vision techniques used in artificial intelligence. By implementing retina-inspired filtering and V1-style edge detection, I learned how the human visual system processes images before higher-level recognition occurs.

One of the most interesting parts of the lab was experimenting with center-surround receptive fields using Difference of Gaussians (DoG) filters. These filters enhanced edges and contrast in images while suppressing unnecessary background information. This demonstrated how the retina performs early-stage preprocessing before visual signals are sent deeper into the brain.

I also learned how Gabor filters simulate orientation-selective neurons found in the primary visual cortex (V1). By applying filters at different angles, the system was able to detect edges, textures, and patterns in multiple orientations. This helped me understand how the brain identifies important visual features from complex environments.

The lab also demonstrated strong connections between neuroscience and artificial intelligence. Many convolutional neural networks (CNNs) use feature extraction methods similar to biological vision systems. Early CNN layers often learn edge detectors and texture filters that closely resemble Gabor-like receptive fields found in the visual cortex.

Another important concept I learned was lateral inhibition and how biological systems improve contrast and sharpen visual perception. The retina-inspired processing pipeline showed how the brain reduces noise and focuses on important information before higher-level interpretation occurs.

Overall, this lab strengthened my understanding of bio-inspired computer vision and demonstrated how neuroscience principles continue to influence modern artificial intelligence systems. It showed how biological perception systems can inspire more efficient, adaptive, and accurate visual processing architectures in AI and machine learning applications.
